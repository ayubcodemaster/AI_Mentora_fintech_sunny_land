# AI Mentora

A 2D farming game built with Unity.

## How to Run on PC (Without Unity)

### Step 1: Build the Game in Unity

1. Open the project in Unity (version 2022.3.20f1 or later)
2. Go to **File → Build Settings**
3. Select **Windows, Mac, Linux** as the platform
4. Click **Build**
5. Choose a folder to save the build (e.g., `Builds/Windows`)
6. Wait for the build to complete

### Step 2: Run the Game

1. Navigate to the folder where you built the game
2. Double-click the `.exe` file (e.g., `AI_Mentora.exe`)
3. The game will launch

## Controls

### PC (Keyboard & Mouse)
- **WASD / Arrow Keys** - Move character
- **Mouse** - Aim / Select target
- **Left Click** - Use tool / Interact
- **Q / E** - Switch inventory items
- **Mouse Scroll** - Zoom in/out

### Mobile (Touch)
- **Joystick** (bottom left) - Move character
- **Tap on ground** - Use tool on that tile
- **Tap on objects** - Interact with NPCs, shops, etc.
- **Swipe left/right on inventory bar** - Switch items
- **Pinch** - Zoom in/out

## Features

- 2D farming gameplay
- Mobile touch controls with virtual joystick
- Camera zoom (scroll wheel + pinch-to-zoom)
- Interactive shops (Market, Dairy, Meat)
- Day/night cycle (currently frozen to daytime)
